## Reproduction

```sh
make evaluate-ami-vad
go run ./cmd/whisper-cpp-streaming/ami-eval --offline --workers 4 --check
```

`make evaluate-ami-vad` (or `go run ./cmd/whisper-cpp-streaming/ami-eval`) runs validate ->
acquire -> prepare/evaluate tuning -> select -> prepare/evaluate held-out -> gate ->
render from an empty cache. Only one split's audio is in memory at a time. Flags:

- `--manifest` -- path to the corpus manifest (default: the committed
  `cmd/whisper-cpp-streaming/ami-eval/manifest.json`).
- `--cache` -- cache directory (default: `.cache/ami-vad-eval/` under the module
  root, which is git-ignored). Any other path may be used for a shared, hosted, or
  preseeded cache, except that a path aliasing (or nested under) a repository
  source/output directory is rejected before any cache use.
- `--offline` -- forbid all network use; every required object must already be
  present and verified in the cache, or the run fails closed before evaluation.
- `--workers` -- concurrent recording workers, capped at 4; each worker owns at
  most one recording (and its own fresh detector and session) at a time. Downloads
  remain sequential regardless of this setting.
- `--check` -- render the report and compare it against the committed file without
  replacing it; exits non-zero on any difference, or when the decision's final
  threshold differs from the runtime default or the live schema default.
- `--report` -- output report path (default: the committed
  `docs/ami-vad-evaluation.md`).

A grid-edge winner, missing or duplicate evidence, an undefined or non-finite decision
metric, a checksum failure, or a detector failure or timeout stops the run with context
and leaves the existing report untouched. A failed held-out gate is a successful
evaluation with a keep decision.

### Cache layout

```text
<cache>/downloads/<sha256>                                   verified source objects
<cache>/prepared/<manifest-digest>/<recording-id>/           canonical audio + reference + provenance
<cache>/results/<manifest-digest>/<evaluation-version>/      results.json (both matrices, summaries, selection, decision)
```

Downloads are sequential, HTTPS-only across redirects, subject to a 15-minute
per-object timeout and a manifest byte ceiling enforced while streaming, and
promoted atomically only after size and SHA-256 verification. A cached object that
fails rehashing is quarantined (renamed aside) with a diagnostic rather than reused
or silently deleted. Each recording/detector run has a deadline of
`min(30m, max(1m, 2*audio duration))`; exceeding it is fatal.

No credentials are ever accepted or persisted by this tool; a protected source must
be preseeded at its checksum-addressed cache location before an offline run.

### Reproducibility

Byte-identical report output is promised only for repeated runs with an identical
corpus, manifest, evaluation revision, parameters, threshold grid, production defaults,
and recorded execution environment (Go version and OS/architecture, both recorded
above). A different supported environment can produce valid, auditable results while
recording its own environment, without matching this report byte-for-byte.

### Continuous integration

CI never downloads the AMI corpus or runs this evaluation end to end. Its corpus-free
tests -- manifest splits, grid construction, evidence validation, selection, gates,
orchestration order, and report rendering -- run against synthetic audio and minimal
annotation fixtures as part of the normal Go test suite.
