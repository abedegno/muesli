# Code of Conduct

## Our pledge

The Muesli community is committed to providing a welcoming, harassment-free
experience for everyone, regardless of background or identity. We want
participation in the project — issues, pull requests, discussions, and reviews —
to be a respectful and constructive experience for all.

## Our standard

This project **adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1**, as its code of conduct. The full text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be kind, assume good faith, give and accept feedback gracefully, and
focus on what's best for the community. Behavior that the Covenant identifies as
unacceptable is not tolerated in any project space.

## Scope

This Code of Conduct applies within all project spaces — the repository, issues,
pull requests, discussions, and any other channel the project uses — and when an
individual is representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to
the maintainers. Use **GitHub's private vulnerability/abuse reporting** on the
repository, or contact a maintainer directly. All reports will be reviewed and
handled confidentially. See the enforcement guidelines in the Contributor
Covenant for how maintainers will respond:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines>
